# Demande n° 30 : l'arme dans le dos, le petit saut pour tirer, et les lasers

> Demandée par Maxance. Les règles marquées ✍️ ont été précisées par Maxance quand Claude lui a
> posé des questions (réponses : 1b avec un petit saut, 2b, 3b, 4b, 5b). Statut : ✅ livrée le 04/10/2026, à valider.

## 🎯 Quoi
- Bug : collé à une tour avec le lance-flammes, il se lève en l'air. Il doit rester accroché au dos.
- Quand on monte avec une arme, elle se range dans le dos, comme une épée dans son fourreau.
- Quand on atterrit : une animation où le héros sort son arme.
- Sur un escalier (plus tard aussi une échelle) : il monte comme un soldat, l'arme pointée vers le bas.
- Un petit laser vert sur la mitrailleuse (« pour faire plus élite »), le Magnum, le lance-roquettes,
  le fusil à pompe et le sniper : il montre où partira le tir.
- Le pistolet laser fait un bruit plus « science-fiction ».

## ⚙️ Comment (les règles)
- ✍️ 1b : collé à un mur, l'arme va dans le dos. T la ressort, et le héros fait tout seul un petit saut
  (sans toucher une autre touche) pour tirer par-dessus le mur. Le tir part en haut du saut.
- ✍️ 2b : l'arme va dans le dos quand le héros monte (saut). En retombant, elle y est encore. Sur un
  escalier, elle ne va pas dans le dos : elle est pointée vers le bas, et le héros se penche un peu.
- ✍️ 3b : arme dans le dos + T : il la sort très vite (0,15 s) et tire tout de suite. En l'air, il
  la garde ensuite en main jusqu'au sol.
- ✍️ 4b : à l'atterrissage, il la sort en 0,6 s avec un « shliiing ! ».
- ✍️ 5b : seulement les armes (épées et armes à feu) vont dans le dos. La hache, la pelle, la
  pioche, les briques, la porte et l'escalier restent en main.
- Choisi par Claude :
  - le réservoir du lance-flammes et le carquois du bazooka sont accrochés au dos : ils ne bougent plus ;
  - l'épée se range dans un fourreau en cuir, et sa poignée dépasse de l'épaule ;
  - les armes à feu se portent en bandoulière ;
  - le petit saut fait 48 px (environ 1 bloc) ;
  - les lasers sont verts, avec un point qui clignote là où ils touchent ;
  - le sniper perd son laser rouge : il a le laser vert, comme les autres.

## ✅ Critères de réussite
- [ ] Je saute avec l'épée : elle va dans le dos. J'atterris : il la sort (« shliiing ! »).
- [ ] Collé à une tour avec le lance-flammes : rien ne s'envole, le réservoir reste sur le dos.
- [ ] Collé à un mur avec le Magnum, T : petit saut tout seul, et le tir passe par-dessus le mur.
- [ ] En l'air, arme dans le dos, T : il la sort vite et tire.
- [ ] Sur un escalier avec une arme : pose de soldat, arme vers le bas.
- [ ] Laser vert sur la mitrailleuse, le Magnum, le bazooka, le fusil à pompe et le sniper.
- [ ] Le pistolet laser fait « vwiiiou-ou-ou ».
