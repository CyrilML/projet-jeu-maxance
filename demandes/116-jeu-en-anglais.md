# Demande n° 116 : le jeu en anglais (bouton FR / EN)

> Statut : ✅ livrée (tanks version 66).
> ✍️ = ce qu'Iron Wolf Studio a décidé.

## 🎯 Quoi
✍️ « Je veux le jeu entier en anglais. » → précisé : ✍️ « Bouton FR / EN ».

## ⚙️ Comment — choix de Claude
- Un réglage de langue (⚙️ Réglages, et un petit bouton FR / EN sur l'accueil), sauvegardé. Le français reste la langue
  de départ.
- En anglais : tout ce que le joueur voit et entend est traduit : accueil, menus, armurerie, boutique, vitrine des
  personnages, éditions, écran de jeu, messages, sous-titres et voix de la radio (voix anglaises du navigateur),
  campagne (textes, briefings, cinématiques), bande-annonce, noms des pays inventés gardés (ce sont des noms propres).
- Restent en français : le carnet et le panneau « sous le capot » (ce sont les outils d'apprentissage d'Iron Wolf Studio),
  et les commentaires du code.
- Les traductions sont rangées comme des données (un dictionnaire), pas mélangées au code.

## ✅ Critères de réussite
- [x] Tanks « version 66 ».
- [x] Le bouton FR / EN, gardé après rechargement.
- [x] En anglais, aucun texte français visible pendant le jeu (hors sous le capot).
