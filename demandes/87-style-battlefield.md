# Demande n° 87 : le style Battlefield

> Statut : 🟡 version 5 minutes livrée le 20/10/2026 (tanks version 27) : le filtre de cinéma. Refaire les objets eux-mêmes reste à faire.
> ✍️ = ce qu'Iron Wolf Studio a décidé.

## 🎯 Quoi
✍️ « Je veux que les décors, les soldats, les tanks, les villes et les souterrains soient dans le même style que
Battlefield. En 5 minutes. »

## ⚙️ Comment (les règles)
- En 5 minutes, on ne peut pas redessiner tous les objets. Une grande partie du « style Battlefield » vient du
  **traitement de l'image** (l'étalonnage, comme au cinéma), posé par-dessus TOUT le jeu (décors, soldats, tanks, villes,
  souterrain) :
  - couleurs un peu éteintes et plus de contraste ;
  - les ombres vers le bleu-vert, les lumières vers l'orange ;
  - les bords de l'écran plus sombres (vignettage) ;
  - un léger grain de caméra qui bouge.
- Réglages : `tanks/config.js` (`ambiance`).

## ✅ Critères de réussite
- [ ] Tanks « version 27 ».
- [ ] L'image est plus sombre et plus « guerre », sur toutes les cartes ; le tableau de bord reste net.
