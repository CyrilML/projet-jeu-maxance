# Demande n° 113 : le camion antiaérien

> Statut : ✅ livrée (tanks version 57).
> ✍️ = ce qu'Iron Wolf Studio a décidé.

## 🎯 Quoi
✍️ « Le canon antiaérien, il est mauvais. Je ne connais pas ça. Je veux que tu fasses un camion. Toi, tu pilotes le
camion, et quelqu'un d'autre tire avec le canon antiaérien. »

## ⚙️ Comment (les règles) — choix de Claude
- Le canon antiaérien fixe (la DCA) est remplacé par un CAMION ANTIAÉRIEN : un camion militaire avec un canon double
  sur son plateau, garé au parking de ta base.
- Toi (E) : tu conduis. Un soldat de ton camp, le tireur, est assis au canon : il vise et tire TOUT SEUL sur les avions
  et les hélicos ennemis à portée. Tu peux aussi prendre sa place (touche F : changer de siège, le camion s'arrête).
- L'ennemi a le même camion, conduit par l'ordinateur, près de sa base.
- Tout se voit sous le capot (cible du tireur, tirs, avions abattus).

## ✅ Critères de réussite
- [x] Tanks « version 57 ».
- [x] Je conduis le camion ; le tireur abat les avions tout seul.
- [x] Le camion ennemi tire sur mes avions et hélicos.
