# Demande n° 66 : plus de son quand on quitte le site

> Statut : ✅ livrée le 08/10/2026 (tanks version 7, rallye-raid version 2), à valider par Maxance.

## 🎯 Quoi
« Quand je quitte le site, je ne veux plus qu'il y ait de son. »

## ⚙️ Comment (les règles)
- Quand tu quittes le jeu (un autre onglet, une autre application, une autre fenêtre devant, ou la page qui se
  ferme), le son « s'endort » : le synthétiseur du jeu est mis en pause. Il se réveille quand tu reviens.
- Le jeu de course à pied (`jeu/`) et le circuit le faisaient déjà (étape 29) ; c'est maintenant aussi le cas des
  tanks et du rallye-raid (le village n'a pas de son).
- Visible sous le capot : « 🔇 Le son s'endort » / « 🔊 le son se réveille » dans le journal, et la ligne « le son »
  dans l'état des tanks.

## ✅ Critères de réussite
- [ ] Dans les tanks, avec le son : je change d'onglet ou d'application → silence.
- [ ] Je reviens → le son repart.
- [ ] Pareil dans le rallye-raid.
